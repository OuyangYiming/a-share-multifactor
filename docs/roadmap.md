# 阶段任务与验收顺序

本计划对应用户提供的任务书. 当前逐模块执行，不把待办写成已完成成果.

| 阶段 | 计划时间 | 交付与验收 |
|---|---|---|
| 0 | 2026-11-09 至 11-15 | 环境、私有仓库、单只股票日线图已准备，本人解释 DataFrame 待验收. |
| 1 | 至 2026-11-22 | data.py 五股下载与字段覆盖试点已实现；完整历史证券池、状态与估值字段、正式年度样本和剔除数量、外部价格抽查仍待完成. |
| 2 | 2026-11-23 至 12-06 | 分次实现 8–12 个因子、MAD、标准化、中性化及 IC / RankIC；十只股票手算检验；时点信息测试. |
| 3 | 2026-12-07 至 12-20 | 月度五层等权回测、交易限制与单边 0.1% / 0.2% / 0.3% 成本；净值、回撤、换手和基准. |
| 4 | 2026-12-21 至 2027-01-03 | 2015–2021 样本内、2022–2025 样本外；滚动检验和预先固定参数；综合信号与三种组合方式比较. |
| 5 | 2027-01-04 至 01-17 | 根据真实结果写 5–8 页 LaTeX 报告、README 与简历；同学复现后验收. |

下一小任务为补齐历史证券池与时点元数据，依据已生成的字段覆盖表逐项验证. 在确认总市值、历史行业、退市与北交所覆盖之前，不批量构建全市场样本.

回测阶段的“故意引入未来函数”必须作为隔离的负面测试，泄漏版本不得进入正式结果. 检验应确认框架能检测泄漏，并记录观察到的差异；不能为了满足“收益明显虚高”而修改数据或捏造收益.

阶段 4 的因子方向、选择、权重和参数只能使用样本内信息或当时可得的滚动训练信息确定. 对样本外结果做完评价后，不得再按其表现重新选择并把它继续称为未使用的样本外数据.
