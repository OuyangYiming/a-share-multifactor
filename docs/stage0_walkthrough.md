# 阶段 0：日线表、索引与缓存

## 本模块的数据流

`run_all.py` 调用 `load_example()`：已有本地数据就读取，没有数据才通过 AKShare 读取腾讯行情. 数据通过 `validate_daily()` 校验，转为按日期排序的 DataFrame，最后由 `write_results()` 生成表格与收盘价图.

`src/example.py` 当前只有数据准备与绘图，不计算因子，不模拟交易. 因此不能用本模块的测试结果宣称回测没有未来函数.

## DataFrame 的行、列与索引

DataFrame 是二维表. 本例每一行表示浦发银行一个交易日的记录；`close` 列是后复权收盘价，`code` 列是证券代码. CSV 缓存读取时先保留为字符串，再明确转换日期与数值，避免隐式转换造成误判. 成交量、成交额与交易状态将在数据管道阶段加入.

`set_index('date')` 把日期列设置为行索引. 索引用于标识与选择行，不是额外的行情指标. `frame.index` 取日期索引，`frame.columns` 取列名，`frame['close']` 取收盘价这一列. 本例只有一只股票，日期可以唯一标识一行；未来扩展到全市场，需要用 `(date, code)` 共同标识一条记录.

在项目根目录、已安装依赖的 Python 环境中运行以下真实数据练习：

```python
from pathlib import Path
from src.example import load_example

frame, metadata = load_example(Path.cwd(), offline=True)
print(frame.head())
print(frame.index.name)
print(frame.columns.tolist())
print(frame['close'].head())
print(frame.loc['2020', ['code', 'close']].head())
```

`head()` 默认显示前几行. `loc` 通过索引标签选行；日期索引支持用年份字符串选择该年的记录. `iloc[0]` 按位置取第一行，不表示某个特定日期.

## 为什么做这些校验

`(date, code)` 重复会使同一日同一股票被重复计入. 证券代码不一致、区间外日期和错误复权标记说明缓存结构与本例约定不一致. 收盘价缺失、无穷或非正时程序直接失败，不用零代替，也不填入未来日期的值. 本例的代码和复权标记来自请求参数，不能独立证明上游没有返回错误证券或错误复权数据；仍需行情对照与复权口径核查.

后复权表示对除权除息作连续化处理. 后复权收盘价与当天交易所显示的不复权报价不一定相等. 对照行情软件时必须同时核对代码、日期、复权方向和算法.

## 为什么缓存并记录 SHA256

缓存减少重复联网，并固定当前研究输入. SHA256 是文件内容的校验值：本例参考记录与实际文件不一致时，程序停止. 校验值可以发现输入变化，但不能证明数据来源正确、历史覆盖完整或没有未来信息. 真正的数据质量仍需独立抽查.

`--offline` 只读本地缓存. 没有缓存时明确报错，而不是生成示例行情. 单元测试中的小表是程序测试用的构造值，与真实行情隔离，不进入研究结果.
